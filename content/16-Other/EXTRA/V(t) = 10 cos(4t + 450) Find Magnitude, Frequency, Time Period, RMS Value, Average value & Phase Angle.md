## V(t) = 10 cos(4t + 45°)

**Standard form:** V(t) = Vm cos(ωt + φ)

Comparing: Vm = 10, ω = 4, φ = 45°

---

### Results

| Quantity | Formula | Answer |
|---|---|---|
| Magnitude | Vm | **10 V** |
| Phase Angle | φ | **45°** |
| Angular Frequency | ω | **4 rad/s** |
| Frequency | ω / 2π | **0.637 Hz** |
| Time Period | 2π / ω | **1.571 s** |
| RMS Value | Vm / √2 | **7.071 V** |
| Average Value | (2/π) × Vm | **6.366 V** |

---

### Working

$$f = \frac{\omega}{2\pi} = \frac{4}{2\pi} = 0.637 \text{ Hz}$$

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{4} = 1.571 \text{ s}$$

$$V_{rms} = \frac{V_m}{\sqrt{2}} = \frac{10}{\sqrt{2}} = 7.071 \text{ V}$$

$$V_{avg} = \frac{2}{\pi} \times V_m = 0.6366 \times 10 = 6.366 \text{ V}$$
