## I(t) = 2 sin(5t − 45°)

**Standard form:** I(t) = Im sin(ωt + φ)

Comparing: Im = 2, ω = 5, φ = −45°

---

### Results

| Quantity | Formula | Answer |
|---|---|---|
| Magnitude | Im | **2 A** |
| Phase Angle | φ | **−45° (lagging)** |
| Angular Frequency | ω | **5 rad/s** |
| Frequency | ω / 2π | **0.796 Hz** |
| Time Period | 2π / ω | **1.257 s** |
| RMS Value | Im / √2 | **1.414 A** |
| Average Value | (2/π) × Im | **1.273 A** |

---

### Working

$$f = \frac{\omega}{2\pi} = \frac{5}{2\pi} = 0.796 \text{ Hz}$$

$$T = \frac{2\pi}{\omega} = \frac{2\pi}{5} = 1.257 \text{ s}$$

$$I_{rms} = \frac{I_m}{\sqrt{2}} = \frac{2}{\sqrt{2}} = \sqrt{2} = 1.414 \text{ A}$$

$$I_{avg} = \frac{2}{\pi} \times I_m = \frac{2}{\pi} \times 2 = \frac{4}{\pi} = 1.273 \text{ A}$$

---

### Note on Phase Angle

φ = **−45°** means the current **lags** behind the reference by 45°.
If φ were positive, it would **lead**.
