### Linear ODEs

$$\frac{dy}{dx} + \frac{y}{x \log x} = \frac{\sin 2x}{\log x}$$

$$\frac{dy}{dx} + 2y = e^x + x, \quad y(0) = 1$$

$$dr + (2r\cot\theta + \sin 2\theta)\,d\theta = 0$$

---

### Linear ODE (x as function of y)

$$(1 + y^2)\,dx = (\tan^{-1}y - x)\,dy$$

---

### Exact ODEs

$$(2xy + y - \tan y)\,dx + (x^2 - x\tan^2 y + \sec^2 y)\,dy = 0$$

$$(y^2 e^{xy^2} + 4x^3)\,dx + (2xy\,e^{xy^2} - 3y^2)\,dy = 0$$

$$\frac{dy}{dx} + \frac{y\cos x + \sin y + y}{\sin x + x\cos y + x} = 0$$
---
### Non-Exact ODEs
$$(x^2y - 2xy^2)\,dx - (x^3 - 3x^2y)\,dy = 0$$

$$y(xy\sin xy + \cos xy)\,dx + x(xy\sin xy - \cos xy)\,dy = 0$$

$$(xy^3 + y)\,dx + 2(x^2y^2 + x + y^4)\,dy = 0$$

$$x^4\frac{dy}{dx} + x^3y + \csc(xy) = 0$$

---

### Reducible / Special Form

$$\frac{dy}{dx} = \frac{x^2 + y^2 + 1}{2xy}$$
